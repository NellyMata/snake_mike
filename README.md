## Investigación sobre Pygame

### ¿Qué es Pygame y para qué se utiliza?
Pygame es una biblioteca de Python que proporciona herramientas para desarrollar videojuegos y aplicaciones multimedia en dos dimensiones. Permite crear ventanas, dibujar figuras, mostrar imágenes, reproducir sonidos y detectar las acciones del teclado y el mouse.

### Relación con los temas vistos en clase
Pygame permite aplicar conceptos de programación como:

- **Ciclos:** mantienen el juego funcionando y actualizan constantemente la pantalla.
- **Condiciones:** permiten comprobar colisiones, movimientos y situaciones de victoria o derrota.
- **Eventos:** identifican las acciones del usuario, como presionar una tecla.
- **Estructuras de datos:** las listas pueden almacenar posiciones y segmentos de la serpiente.
- **Funciones:** organizan tareas específicas y evitan repetir instrucciones.
- **Variables:** almacenan información como puntuación, velocidad y posición.

### ¿Qué significa tomar mucho o poco de la biblioteca?
Significa que Pygame ofrece herramientas que pueden utilizarse según las necesidades del proyecto. Un programa sencillo puede usar solamente las funciones para crear una ventana y dibujar figuras. Un videojuego más completo puede incorporar imágenes, sonidos, eventos, colisiones y otras funciones. No es obligatorio utilizar toda la biblioteca.

## Organización de ramas y flujo de trabajo

- **main:** rama principal donde se integran las actividades y se mantiene una versión estable del proyecto.
- **v01:** rama destinada al desarrollo y las pruebas de versiones del videojuego antes de integrarlas a main.
- **actividad1:** contiene el código de la primera actividad con Pygame.
- **actividad2:** contiene el código del videojuego Snake.

El flujo de trabajo consiste en desarrollar los avances en sus respectivas ramas, comprobar su funcionamiento, guardar los cambios mediante commits y fusionar las ramas correspondientes con main. Git permite conservar el historial de versiones y GitHub facilita el almacenamiento y la revisión del repositorio.
